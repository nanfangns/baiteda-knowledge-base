# 全局变量接口

接口都是前端调用需要登录的接口

<a id="VtS2i"></a>


## 全局变量添加

接口地址 /apps/api/v1/private/gv/edit

方法 post

入参


```plain
[{
    "key":  "org_nature",
    "value":"60"
}]
```

<a id="NxhBk"></a>

