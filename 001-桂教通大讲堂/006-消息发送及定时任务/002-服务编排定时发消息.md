## 案例背景

企业每到月底对应对实习生进行考勤信息收集

1. **服务模块**

- **消息发送服务**：将考勤填写链接发送到员工性质为实习生的填报系统中

2. **任务调度模块**

- **定时任务调度器**：每个月最后一天发起考勤填写提醒，10点，14点，17点进行发送

<a id="g1dpR"></a>


## 实现步骤

<a id="XxQi6"></a>


### 前期配置

进入管理后台添加连接器配置


![image.png](../../_assets/axkkgk5lvs3br3ad/image-d6097852b2.png)


添加连接器信息


![image.png](../../_assets/axkkgk5lvs3br3ad/image-1be34da33f.png)


![image.png](../../_assets/axkkgk5lvs3br3ad/image-a20736fb82.png)


<a id="vpUJ9"></a>


### 1. 服务编排

新建一个服务编排，触发方式选择定时触发，服务方式选择其他


![image.png](../../_assets/axkkgk5lvs3br3ad/image-e773225247.png)


服务配置：定时任务每触发一次，调用一次该服务进行发送消息提醒


![image.png](../../_assets/axkkgk5lvs3br3ad/image-e98fe81bb0.png)


<a id="KMGIo"></a>


### 2. 定时任务

进入定时任务配置页面，开始进行定时配置，年月日周时分秒按照自己的要求进行配置


![image.png](../../_assets/axkkgk5lvs3br3ad/image-809a7008ca.png)


![image.png](../../_assets/axkkgk5lvs3br3ad/image-b6774c3d92.png)


![image.png](../../_assets/axkkgk5lvs3br3ad/image-3b23a26bcb.png)


<a id="VN2KJ"></a>


### 3.服务配置

配置连接器信息


![image.png](../../_assets/axkkgk5lvs3br3ad/image-736a84e697.png)


选中对应连接器


![image.png](../../_assets/axkkgk5lvs3br3ad/image-433f4eaa34.png)


**配置输入参数**

参数解读：

agentld：对应IM工具后台应用管理下对应应用的AgentId

![image.png](../../_assets/axkkgk5lvs3br3ad/image-e389a30785.png)


文字内容：需要发送的内容可以写在这里


![image.png](../../_assets/axkkgk5lvs3br3ad/image-4b015a593d.png)


消息类型：文本类型为text

接收人：需要接收到的人员账号写在此处，如果有多人使用英文逗号隔开

通过实施上述的服务编排和定时任务，实现了定时发送消息的操作，员工收到消息后可进行点击链接填写考勤
