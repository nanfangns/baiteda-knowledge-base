# 概述

表单下拉选项有两种选择方式

- 自定义方式：由开发实施人员进入设计页面进行固定维护。


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-77dc6bbdc7.png)


- 关联数据源方式：可从运行页面维护数据源，关联方式能使用系统默认服务，

也可选择自定义的 SQL 服务或高级 HTTP 服务。


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-f339fa7c55.png)


​

<a id="p5l3l"></a>

## 高级HTTP服务

下拉选项的数据源可从外部获取，就需要添加一个高级HTTP服务，以下为配置方式

<a id="OY21A"></a>


### 高级HTTP服务创建

1.进入业务模型，点击模型服务，添加高级HTTP服务


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-812ac8e4db.png)


2.开始添加高级http服务的内容

服务方式选择为查多

Method选择：POST

Body选择：JSON

URL地址：后端服务定义的地址

返回值：点击同步，自动进入

成功标识值：设置为000000


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-f0244bce63.png)


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-8035dc554a.png)


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-13898d1b38.png)


<a id="wMmZ8"></a>


### 服务引用

即可在表单页面的字段中进行配置关联数据源操作

### **查询关键字参数映射**

用户在下拉数据选择时，不仅可以通过手动选择选中数据，也可通过输入映射对应的编码查询到数据将其展示

1.点击进入高级设置


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-c9039c47ec.png)


2.添加数据映射字段，数据的映射字段选项为高级HTTP服务的入参（本demo使用的编码作为映射字段）


![image.png](../../_assets/fzwm9vh9bm6s0k4h/image-3775fdff6c.png)
