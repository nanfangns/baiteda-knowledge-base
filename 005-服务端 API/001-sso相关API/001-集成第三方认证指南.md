## 2.标准Oauth2授权方式的第三方

<a id="D9X79"></a>


### 第一步：第三方提供相关参数：

client\_id：客户端id

client\_secret：客户端秘钥

scope：授权范围

response\_type：固定值：code，目前只支持授权码模式

grant\_type：固定值：authorization\_code

authorize\_url：授权地址

redirect\_url：授权成功后的回传授权码的地址，固定格式：

https://{租户域名}/ego\_base\_info/v1/public/sso/custom/oauth/login?code=xxx

access\_token\_url：获取token的地址

access\_token\_match：token字段的key

content\_type：获取token接口的content-type, 默认application/x-www-form-urlencoded

token\_auth\_type：获取token接口的鉴权模式，不填=oauth2默认鉴权，Basic=basic鉴权模式

get\_userinfo\_url：获取用户数据的接口地址

user\_info\_auth\_type：获取用户信息接口时token的传递方式，目前只支持Bearer方式

user\_info\_need\_client\_id：获取用户信息的接口是否需要传client\_id， 默认false

user\_id\_match：用户id字段的key

user\_name\_match：用户名字段的key

avatar\_url\_match：用户头像字段的key

logout\_url：登出地址，从百特搭退出登录的时候会302到此地址

**以下为参数示例：**


```json
{
  "client_id": "byucgaezXsLiwIJPW4UY",
  "client_secret": "Cw4cZmIalH2EiVj3cF3rZmNrucUDxGlKnKqJ9DZB",
  "scope": "doc,repo,group:read",
  "response_type": "code",
  "grant_type": "",
  "authorize_url": "https://www.yuque.com/oauth2/authorize",
  "redirect_url": "https://yuhanghgj.test.baiteda.com/ego_base_info/v1/public/sso/custom/oauth/login",
  "access_token_url": "https://www.yuque.com/oauth2/token",
  "access_token_match": "$.access_token",
  "get_userinfo_url": "https://www.yuque.com/api/v2/user",
  "user_id_match": "$.data.id",
  "user_name_match": "$.data.name",
  "avatar_url_match": "$.data.avatar_url"
}
```

## 3.cas授权方式的第三方

<a id="dcxcR"></a>


### 第一步：第三方提供相关参数：

client\_id：第三方分配给百特搭的客户端id

authorize\_url：cas授权地址

ticket\_match：授权成功后回传的ticketKey，默认是ticket，可以是其它的，如token、unifyToken等

ticket\_validate\_url：ticket校验地址

ticket\_validate\_return\_data\_type：json/xml，ticket校验通过后返回用户信息的数据格式，默认为json

user\_id\_match：用户id字段的key

user\_name\_match：用户名字段的key

avatar\_url\_match：用户头像字段的key

第三方只需提供以上参数，百特搭会按照标准cas认证流程发起认证。

**参数示例：**


```json
{
  "client_id": "abcde",
  "authorize_url": "https://cas.baiteda.com/authorize",
  "ticket_match": "ticket",
  "ticket_validate_url": "https://cas.baiteda.com/serviceValidate",
  "user_id_match": "$.data.id",
  "user_name_match": "$.data.name",
  "avatar_url_match": "$.data.avatar_url"
}
```


**请求授权时的url示例：**

GET https://cas.baiteda.com/authorize?client\_id=abcde&service=https%3A%2F%2Fyuhanghgj.test.baiteda.com%2Fego\_base\_info%2Fv1%2Fpublic%2Fsso%2Fcustom%2Foauth%2Flogin

**回传token的url示例：**

GET https://yuhanghgj.test.baiteda.com/ego\_base\_info/v1/public/sso/custom/cas/login?ticket=asdfgh

**校验ticket的url示例：**

GET https://cas.baiteda.com/ticketValidate?ticket=asdfgh
