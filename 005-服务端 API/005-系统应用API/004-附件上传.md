## 远程文件上传

**接口地址**：https://{host}/apps/api/v1/public/attachment/uploadFileByUrl

**请求方式**：POST

​

**请求参数**：


```json
{
    "tenant_id":"test",
    "sign":"426ee92528069f3e57e60810ed841e15",
    "biz_params":"{\"remote_files\":[{\"file_name\":\"测试附件.PNG\",\"file_type\":\"PNG\",\"remote_url\":\"https://cloud-store.baiteda.com/shop/attach/image/833ac518-6380-4645-ad56-d7c993ab165c.png \"}],\"storage_enable\":true,\"deleteable\":false}",
    "app_id":"3cxb0315",
    "timestamp":"20210617201223"
}
```


**biz\_params**对象结构：


```json
{

    "remote_files":[
        {
            "file_name":"测试附件", // 存储文件名称
            "file_type":"PNG", // 文件类型
            "remote_url":"https://cloud-store.baiteda.com/shop/attach/image/833ac518-6380-4645-ad56-d7c993ab165c.png " // 远程文件地址

        }
    ],
    "storage_enable":true,  //是否转储(文件是否存储在BPM服务器下)
    "user_id": "sysadmin" //单独调用此接口需要（sdk调用时可以不用传递）
}
```


**返回示例**


```json
{
    "state":"SUCCESS",
    "message":"执行成功",
    "code":"000000",
    "timestamp":"2021-06-17 20:12:23",
    "data":[
        {
            "file_id":"bb8bd8db5d1eb2db975ff4a3c5fdd498",
            "file_name":"测试附件",
            "create_time":"时间戳"
        }
    ]
}
```

## 附件批量下载

**接口地址**：https://{host}/attachment/api/v1/open/batch/download

**请求方式**：POST

​

**请求参数**：


```json
{
    "tenant_id":"test",
    "sign":"426ee92528069f3e57e60810ed841e15",
    "biz_params":"[\"附件id1\",\"附件id2\"]",
    "app_id":"3cxb0315",
    "timestamp":"20210617201223"
}
```


**biz\_params**对象结构：


```json
 [\"附件id1\",\"附件id2\"]
```
