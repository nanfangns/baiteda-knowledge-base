## 1. 注册外部组织

<a id="C9qA5"></a>


### 1.1API调用

**接口地址：**${host}/ego\_base\_info/api/open/register/org

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| org\_type\_id | 组织类型ID  【需要调用服务获取数据来源：mul\_ext\_dept\_type\_info\_selectMore】 | String | 是 |
| org\_name | 组织名称 | String | 是 |

**参考示例：**


```json
{
	"app_id": "btdev_system_app",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "testqw",
	"biz_params": "{\"tenant_id\":\"testqw\",\"org_type_id\":\"ces\",\"org_name\":\"百特搭\"}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"data": {
		"org_id": "ex_dept_ANnOh1v5",
		"org_name": "百特搭",
		"org_type_id": "ces",
		"tenant_id": "testqw"
	},
	"msg": "success"
}
```

## 2. 注册外部组织成员

<a id="RBAVf"></a>


### 2.1API调用

**接口地址：**${host}/ego\_base\_info/api/open/register/user

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| phone | 手机号【唯一校验&格式校验】 | String | 是 |
| email | 邮箱地址【若不为空需要进行唯一校验&格式校验】 | String | 否 |
| employee\_name | 成员姓名 | String | 是 |
| gender | 性别（1-男，2-女） | String | 是 |
| password | 密码 | String | 是 |
| second\_password | 二次确认明码 | String | 是 |
| avatar\_url | 头像地址 | String | 否 |
| register\_user\_depts | 组织角色关联数组信息 | List<Object> | 否 |
| org\_id | 组织ID【需要调用服务获取数据来源：selectMore\_eptkyxvj】【说明】：组织列表需要通过org\_type\_id关联查询 | String | 是 |
| org\_type\_id | 组织类型ID【需要调用服务获取数据来源：mul\_ext\_dept\_type\_info\_selectMore】 | String | 是 |
| roles | 角色ID列表【需要调用服务获取数据来源：mul\_ext\_role\_info\_selectMore】【说明】：角色编码需要通过org\_type\_id关联查询 | List<String> | 是 |

**参考示例：**


```json
{
	"app_id": "btdev_system_app",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "testqw",
	"biz_params": "{\"avatar_url\":\"\",\"email\":\"\",\"employee_name\":\"张三\",\"gender\":\"1\",\"password\":\"Qw123456\",\"phone\":\"17710452105\",\"register_user_depts\":[{\"org_id\":\"ex_dept_ANnOh1v5\",\"org_type_id\":\"ces\",\"roles\":[\"xu1\"]}],\"second_password\":\"Qw123456\",\"tenant_id\":\"testqw\"}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"data": {
    "tenant_id": "testqw",
    "employee_name": "张三",
    "phone": "17711452005",
    "email": "",
    "gender": "1",
    "avatar_url": "",
    "password": "Qw123456",
    "second_password": "Qw123456",
    "register_user_depts": [
      {
        "roles": [
          "xu1"
        ],
        "org_id": "ex_dept_ANnOh1v5",
        "org_type_id": "ces",
        "employee_id": "ex_user_0WCcLnMw"
      }
    ]
  },
	"msg": "success"
}
```
