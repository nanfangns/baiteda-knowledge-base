## 1. 判断用户是否是管理员角色

**接口地址：**${host}/ego\_base\_info/api/group/isSysAdmin

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| employee\_id | 员工id | String | 必填 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "zyddtest",
	"biz_params": "{\"tenant_id\":\"test\", \"employee_id\":\"zhangsan\"}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data": false
}
```

## 2. 查询角色列表

**接口地址：**${host}/ego\_base\_info/api/group/selectGroup

**请求方式：**POST

**Body中biz\_params参数：**

| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| current\_employee\_id | 当前用户id（已弃用） | String | 否 |
| employee\_id | 用户id | String | 是 |
| page\_index | 页码 | Integer | 是 |
| page\_size | 单页查询条数 | Integer | 是 |

| deleted | 是否删除：1=已删除，0=未删除 | Integer | 否 |

## 4. 保存角色和用户关系

**接口地址：**${host}/ego\_base\_info/api/group/saveGroupAndRelation

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| group\_code | 角色编码 | String | 是 |
| group\_name | 角色名称 | String | 是 |
| operate\_user | 创建人 | String | 是 |
| group\_description | 角色描述 | String | 否 |
| group\_details | 角色下的员工信息 | array | 否 |
| group\_details.employee\_id | 员工id | String | 否 |
| group\_details.management\_scope\_list | 管理维度 | array | 否 |
| group\_details.management\_scope\_list.type | 按什么维度给人员和人员关联，固定值：dept | String | management\_scope\_list内必填 |
| group\_details.management\_scope\_list.value | type=dept的时候，这里传部门id | String | management\_scope\_list内必填 |
| group\_details.management\_scope\_list.has\_child | 是否级联关联这个部门的所有子部门 | Booelan | management\_scope\_list内必填 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "test",
	"biz_params": "{\"tenant_id\":\"zyddtest\",\"group_code\":\"666666\",\"group_name\":\"测试角色666\",\"operate_user\":\"805759\",\"group_description\":\"测试角色的描述\",\"group_details\":[{\"employee_id\":\"805759\",\"management_scope_list\":[{\"type\":\"dept\",\"value\":\"GO_1c6541fc83fc44e3b2419258f10a70db\",\"has_child\":true},{\"type\":\"dept\",\"value\":\"GO_9134ce5f9cca41758071645c5351f876\",\"has_child\":true}]},{\"employee_id\":\"805762\",\"management_scope_list\":[{\"type\":\"dept\",\"value\":\"GO_1c6541fc83fc44e3b2419258f10a70db\",\"has_child\":true},{\"type\":\"dept\",\"value\":\"GO_30ebce64dfb0456eaf44af063d6ed630\",\"has_child\":true}]}]}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data": true
}
```

## 8. 维护角色下人员接口

**接口地址：**${host}/ego\_base\_info/api/group/incrementGroupAndRelation

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| group\_code | 角色code | String | 是 |
| tenant\_id | 租户ID | String | 是 |
| delete\_id\_list | 删除用户ID | List<String> | 否 |
| delete\_all | 是否删除全部，默认为false | boolean | 否 |
| group\_details | 增量人员 | List<对象> | 否 |
| employee\_id | 人员ID | String | 否 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "zyddtest",
	"biz_params": "{\"delete_id_list\":[\"删除ID1\",\"删除ID2\"],
  \"group_details\":[{\"employee_id\":\"新增ID\"}]}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data":true
}
```
