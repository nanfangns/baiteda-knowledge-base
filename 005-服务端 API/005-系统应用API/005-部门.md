## 1. 同步部门数据

**接口地址：**${host}/ego\_base\_info/api/department/syncDept

注意：接口支持部门禁用，但不会对禁用部门是否还有用户 \ 是否还有子部门进行校验

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| clear\_all | 是否删除现有全部部门，默认false | boolean | 否 |
| department\_list | 要同步的部门集合 | array | 否 |
| department\_list.department\_id | 部门id | String | 否 |
| department\_list.department\_name | 部门称 | String | 否 |
| department\_list.parent\_department\_id | 父部门id | String | 否 |
| department\_list.order | 排序值 | Integer | 否 |
| department\_list.deleted | 是否删除,1=是， 0=否，默认是0 | Integer | 否 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "zyddtest",
	"biz_params": "{\"tenant_id\": \"zyddtest\",\"clear_all\": false,\"department_list\": [{\"department_id\": \"805759\",\"department_name\": \"测试用部门\",\"parent_department_id\": \"1\",\"order\": 2}]}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data": false
}
```

## 3. 创建或者更新部门信息

**接口地址：**${host}/ego\_base\_info/api/department/createOrUpdateDept

**请求方式：**POST

注意：接口不支持部门禁用

**Body中biz\_params参数：**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 | 说明 |
| tenant\_id | 租户id | String | 是 | ​ |
| department\_id | 部门编码，  1.传了若能查询到代表更新；  2.传了若查询不到代表新增；  3.不传代表新增 | String | 否 | ​ |
| department\_name | 部门名称 | String | 是 | ​ |
| department\_en\_name | 部门英文名称（仅保存暂未启用） | String | 否 | ​ |
| parent\_department\_id | 父部门ID | String | 是； | 根路径部门ID不支持通过API创建 |
| dept\_id\_path | 部门id路径 | String | 否 | ​ |
| dept\_name\_path | 部门名称路径 | String | 否 | ​ |
| order | 排序值 | Integer | 否 | ​ |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "zyddtest",
	"biz_params": "{\"tenant_id\": \"zyddtest\",\"department_id\": \"805759\",\"department_name\": \"接口测试部门\",\"department_en_name\": \"接口测试部门\",\"parent_department_id\": \"1\",\"dept_id_path\": \"1\",\"dept_name_path\": \"专有钉钉测试\",\"order\": 2}"
}
```

```json
    "dept_id_path": "0_4",
    "dept_name_path": "测试1",
    "order": 0,
    "create_time": "2022-09-06 18:02:46",
    "update_time": "2022-09-06 18:02:46",
```

## 4. 根据部门id删除部门（部门禁用）

**接口地址：**${host}/ego\_base\_info/api/department/deleteDept

注意：部门禁用

（1）部门下不能有未删除子部门

（2）部门下不能有启用状态员工

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| department\_id | 部门id | String | 是 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "test",
	"biz_params": "{\"tenant_id\": \"zyddtest\",\"group_code\": \"666666\",\"group_name\": \"测试角色666\",\"operate_user\": \"805759\",\"group_description\": \"测试角色的描述\",\"group_details\": [{\"employee_id\": \"805759\"},{\"employee_id\": \"805762\"}]}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data": true
}
```

## 6. 根据部门id清除部门负责人redis缓存

**接口地址：**${host}/ego\_base\_info/api/department/removeDeptCache

**请求方式：**POST

**Body中biz\_params参数：**

**更新日期：2023/10/27**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| tenant\_id | 租户id | String | 是 |
| department\_ids | 部门ID集合 | List<String> | 是 |

**参考示例：**


```json
{
	"app_id": "app001",
	"sign": "sign001",
	"sign_type": "md5",
	"timestamp": "20220222165400",
	"tenant_id": "zyddtest",
	"biz_params": "{\"tenant_id\":\"zyddtest\",\"department_ids\":[\"1\"]}"
}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"data": true
	"msg": "success"
}
```
