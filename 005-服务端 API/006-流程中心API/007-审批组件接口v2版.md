## 1.1校验是否有权限打开

接口地址：${host}/ego\_api/auth/v2/permission/has

**请求方式：**POST

**Body参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 是否必填 |
| process\_instance\_id | 流程实例id | String | 必填 |

**参考示例：**


```json
{"process_instance_id":"fd3945c6-6fb1-4df9-a095-3630a9012671"}
```


**返回参考示例：**


```json
{
	"code": "000000",
	"message": "成功",
	"data": true   /* true:有权限  false:无权限 */
}
```
