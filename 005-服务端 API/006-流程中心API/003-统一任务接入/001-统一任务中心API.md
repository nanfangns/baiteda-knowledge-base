## 1.添加或更新流程定义

将外部系统的流程定义信息推送至流程中心。当流程定义（单据）信息存在时直接更新。

**接口地址：**${host}/ego\_api/api/v1/unify/addOrUpdateProcessInfo

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 说明 | 类型 | 是否必填 |
| process\_def\_key | 流程定义key | String | 是 |
| process\_name | 流程定义中文名称 | String | 否 |
| process\_name\_en | 流程定义英文名称 | String | 否 |
| process\_name\_ja | 流程定义日文名称 | String | 否 |

**参考示例：**


```json
{
    "app_id": "approval-portal",
    "biz_params": "{\"process_def_key\":\"test_out_process\",\"process_name\":\"外部流程对接\",\"process_name_en\":\"外部流程对接en\",\"process_name_ja\":\"外部流程对接ja\",\"host\":\"\"}",
    "sign": "b981877c83d664f26491ae8870d612b2",
    "tenant_id": "test",
    "timestamp": "20220428154630"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "data": true,
    "message": "成功"
}
```

## 2.添加流程实例

将外部系统的流程实例信息推送至流程中心。

**接口地址：**${host}/ego\_api/api/v1/unify/addProcessInstance

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 说明 | 类型 | 必填 |
| process\_instance\_id | 流程实例id，全局唯一，建议使用uuid或者雪花id | String | 是 |
| biz\_key | 业务关联健值 | String | 是 |
| process\_def\_id | 流程定义id | String | 否 |
| process\_def\_key | 流程定义的key | String | 是 |
| process\_def\_name | 流程定义的名称 | String | 是 |
| subject | 任务主题 | String | 是 |
| initiator | 流程发起人id | String | 是 |
| status | 流程状态：COMPLETE/RUNNING/TERMINATION | String | 是 |
| start\_time | 流程发起时间戳(精确到毫秒)，例1650188221891 | long | 是 |
| process\_location | 流程当前所在节点名称，多个以逗号隔开，如果不传，在我的申请列表里面将展示为空。流程结束时可填写为空 | String | 否 |
| form\_uri\_view | 我的申请跳转链接 | String | 否 |

**参考示例：**


```json
{
    "app_id": "approval-portal",
    "local": "zh-CN",
    "sign": "a688b2b3653fb797f4b39e6f52cf931d",
    "biz_params": "{\"process_instance_id\":\"9876789876124\",\"biz_key\":\"ty980872\",\"process_def_key\":\"test_out_process\",\"process_def_name\":\"外部流程对接\",\"subject\":\"外部流程对接ty980872\",\"initiator\":\"LiuCanCan\",\"status\":\"RUNNING\",\"start_time\":1650426418531,\"process_location\":\"法务审批\"}",
    "tenant_id": "test",
    "timestamp": "20220428160155"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "data": true,
    "message": "成功"
}
```

## 4.添加任务实例

将外部系统的任务实例信息推送至流程中心。

**接口地址：**${host}/ego\_api/api/v1/unify/addTask

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 说明 | 类型 | 必填 |
| task\_instance\_id | 任务实例id | String | 是 |
| process\_instance\_id | 流程实例id | String | 是 |
| process\_def\_id | 流程定义id | String | 否 |
| process\_def\_key | 流程定义key | String | 是 |
| process\_def\_name | 流程定义名称 | String | 是 |
| node\_id | 当前所在节点id | String | 是 |
| node\_name | 当前所在节点的名称 | String | 是 |
| to\_do\_url | 待办任务url地址 | String | 是 |
| subject | 任务主题 | String | 是 |
| assignees | 任务处理人。多人竞争审批时，传多个。 | List<String> | 是 |
| create\_time | 创建时间戳(精确到毫秒)，例1650188221891 | long | 是 |
| biz\_key | 业务关联健值 | String | 是 |

**参考示例：**


```json
{
    "app_id": "approval-portal",
    "local": "zh-CN",
    "sign": "97282fc979bd2313514f726539507b0b",
    "biz_params": "{\"task_instance_id\":\"7896658098734\",\"process_instance_id\":\"9876789876124\",\"biz_key\":\"ty980872\",\"process_def_key\":\"test_out_process\",\"process_def_name\":\"外部流程对接\",\"node_id\":\"userTask2\",\"node_name\":\"法务审批\",\"to_do_url\":\"https://www.baidu.com\",\"subject\":\"外部流程对接ty980872\",\"assignees\":[\"LiuCanCan\"],\"create_time\":1650426418531}",
    "tenant_id": "test",
    "timestamp": "20220428160816"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "data": true,
    "message": "成功"
}
```

## 5.更新任务实例

更新任务实例。

**接口地址：**${host}/ego\_api/api/v1/unify/updateTask

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 说明 | 参数类型 | 必填 |
| task\_instance\_id | 任务实例id | String | 是 |
| done\_url | 已办任务url地址，如果不传则使用待办url | String | 否 |
| assignee | 任务处理人，如果不传任务处理人则认为任务是自动结束。 | String | 否 |
| end\_time | 完成时间戳(精确到毫秒)，例1650188221891 | long | 是 |
| command\_type | 审批按钮类型 | String | 是 |
| command\_message | 审批结果，同意、拒绝、转发等 | String | 是 |
| task\_comment | 审批意见 | String | 否 |

**参考示例：**


```json
 {
    "tenant_id":"test",
    "sign":"39d7bf3a535cbfa1e247f1690d6eac07",
    "app_id":"testqwq",
    "sign_type":"md5",
    "timestamp":"20230828171852",
    "biz_params":"{\"task_instance_id\":\"dfb6c34f-83c3-4c3b-9489-ad266aebb610\",\"command_type\":\"general\",\"command_message\":\"同意\",\"done_url\":\"https://www.baidu.com\",\"assignee\":\"f77d81fa\",\"end_time\":1693214332032,\"task_comment\":\"接口提交\",\"subject\":\"验证更新任务实例成功\"}"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "data": true,
    "message": "成功"
}
```

## 6.删除实例数据

**接口地址：**${host}/ego\_api/api/v1/unify/deleteInst

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 说明 | 参数类型 | 必填 |
| task\_instance\_id | 任务实例id | List<String> | 2个必须一个有值，同时有值时，  以流程实例ID为准，删除该流程实例的  所有数据 |
| process\_instance\_id | 流程实例id | String |

**参考示例：**


```json
{
    "app_id": "approval-portal",
    "local": "zh-CN",
    "sign": "97282fc979bd2313514f726539507b0b",

    "tenant_id": "test",
    "timestamp": "20220428160816"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "data": true,
    "message": "成功"
}
```
