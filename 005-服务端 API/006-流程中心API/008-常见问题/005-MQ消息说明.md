# 流程状态更新MQ

<a id="ySN3H"></a>


## topic： p\_WFC\_TASK\_STATUS\_DELAY\_TENANT

<a id="kD93C"></a>


###

新加入consumer时，注意对历史消息的过滤，过滤方式

通过消息时间强制忽略

<a id="Q1DUi"></a>


## 参考示例：

每个业务系统监听MQ时，consumer都是独有的，且在集群部署时，监听mq的策略也是集群模式(MessageModel.CLUSTERING)


```java
@Component
@Slf4j
@RocketMQMessageListener(topic = "p_WFC_TASK_STATUS_DELAY_TENANT", consumerGroup = "xxxxx", messageModel = MessageModel.CLUSTERING)
public class DefaultMessageConsumer implements RocketMQListener<MessageExt>, RocketMQPushConsumerLifecycleListener {

    @Override
    public void prepareStart(DefaultMQPushConsumer consumer) {
        consumer.setConsumeFromWhere(ConsumeFromWhere.CONSUME_FROM_TIMESTAMP);
        consumer.setConsumeTimestamp(UtilAll.timeMillisToHumanString3(System.currentTimeMillis()));
        // 设置唯一clientId
        String instanceName = BaiTeStringUtil.createGuid();
        consumer.setInstanceName(instanceName);
    }

    @Override
    public void onMessage(MessageExt message) {
        if(System.currentTimeMillis()-message.getBornTimestamp()>120*1000) {//2分钟之前的认为过期
            log.info("messageId={},该消息过期了,不在执行逻辑",message.getMsgId());
            return;//过期消息跳过
        }

        String messageBody = new String(message.getBody());
        log.info("messageId={},消息内容={}",message.getMsgId(),messageBody);
        //业务逻辑
    }
}
```

# 新增知会MQ

<a id="KH9rc"></a>


## topic: p\_WFC\_TASKNOTICE\_TENANT

<a id="aFOVq"></a>


## 参考示例：

每个业务系统监听MQ时，consumer都是独有的，且在集群部署时，监听mq的策略也是集群模式(MessageModel.CLUSTERING)


```json
@Component
@Slf4j
@RocketMQMessageListener(topic = "p_WFC_TASKNOTICE_TENANT", consumerGroup = "xxx", messageModel = MessageModel.CLUSTERING)
public class SendNoticeMessageConsumer implements RocketMQListener<MessageExt>, RocketMQPushConsumerLifecycleListener {

    private static final String REQUEST_ID = "requestId";

    @Autowired
    private SendNoticeService sendNoticeService;

    @Override
    public void prepareStart(DefaultMQPushConsumer consumer) {
        consumer.setConsumeFromWhere(ConsumeFromWhere.CONSUME_FROM_TIMESTAMP);
        consumer.setConsumeTimestamp(UtilAll.timeMillisToHumanString3(System.currentTimeMillis()));
        // 设置唯一clientId
        String instanceId = BaiTeStringUtil.createGuid();
        consumer.setInstanceName(instanceId);
    }

    @Override
    public void onMessage(MessageExt message) {

        if(System.currentTimeMillis()-message.getBornTimestamp()>60*2000) {//2分钟之前的认为过期
            return;//过期消息跳过
        }

        MDC.put(REQUEST_ID, UUID.randomUUID().toString(true));
        try {
            String body = new String(message.getBody());
            log.info("msgId={},body={}", message.getMsgId(), body);
            //业务逻辑
        } catch (Exception e) {
            log.warn(e.getMessage(), e);
            return;
        }
        MDC.remove(REQUEST_ID);
    }


}
```
