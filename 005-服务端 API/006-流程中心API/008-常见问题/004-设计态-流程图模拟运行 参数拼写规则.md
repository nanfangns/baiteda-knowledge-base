## 1.不能访问数据库

​

模拟运行入参模板：


```json
{
	"flow_app_map": {
		"app_id": "业务模型所在应用ID",
		"data_code": "业务模型code"
	},
	"flow_info_map": {},
	"form_data_map": {
		"业务模型code": {
			"字段编码": "对应的值"
      ...
		}
	},
	"sub_data_map_single": {},
	"flow_form_map": {
		"表单code": "表单完整路径"
	}
```

## 2.能访问数据库

​

1. 正常发布表单、流程到运行态
2. 正常填写单据，发起流程
3. 根据流程实例ID，到base库 查询 SELECT transient\_param,created\_time FROM ego\_tenant.fixflow\_run\_transient\_variable where processinstance\_id = '流程实例ID';

transient\_param的值即为可使用的流程运行模拟变量

4. 把transient\_param的值拷贝到流程模拟中，使用流程模拟调试流程
