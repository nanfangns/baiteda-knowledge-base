## 1.流程重启接口

**接口地址：**${host}/ego\_api/api/v2/manager/flow/restart

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 必填 |
| process\_instance\_id | 流程实例id | String | 必填 |
| manager\_id | 管理员id | String | 必填 |
| rollback\_node\_id | 重启退回到的节点ID | String | 非必填 |
| task\_comment | 审批意见 | String | 非必填 |

rollback\_node\_id为空时，默认退回到最后一个任务节点上

rollback\_node\_id不为空时，只能填写一个节点ID

**参考示例：**


```json
{
 "app_id":"app001",
 "sign":"sign001",
 "sign_type":"md5",
 "timestamp":"20200911112230",
 "tenant_id":"test",
 "biz_params":"{\"process_instance_id\":\"a3c46fd9-cbf5-47ba-a3d3-bfebbf4151a9\",\"manager_id\":\"zhangsan\",\"rollback_node_id\":\"节点ID\"}"
}
```


**返回参考示例：**


```json
{
    "code": "000000",
    "message": "成功",
    "data": {
        "business_key": "0dac4dfd1adc4367918c8d074d621f56",
        "process_definition_key": "test_zero_ukt2mxqw68",
        "process_location": "UserTask_05b0l6p",
        "process_status": "COMPLETE"
    }
}
```

## 7.流程实例查询

**版本：**3.1.1

**接口地址：**${host}/ego\_api/api/v2/process/ins/selectProInstPage

**请求方式：**POST

**Body中biz\_params参数：**

|  |  |  |  |
| --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 必填 |
| page\_size | 分页大小 | String | 非必填，默认为50 |
| page\_index | 页码 | String | 非必填，默认为1 |
| initiator | 流程发起人 | String | 非必填 |
| subject | 模糊搜索关键字 | String | 非必填 |
| type\_key\_list | 指定流程key集合 | List<String> | 非必填 |
| pro\_inst\_id | 流程实例集合 | List<String> | 非必填 |
| status  | 状态 | String | 非必填 默认返回已完成数据  审批中 approve  已结束 complete  已终止 termination  |

排序方式：默认以流程实例的创建时间 倒序排序。

**参考示例：**


```json
{
 "app_id":"app001",
 "sign":"sign001",
 "sign_type":"md5",
 "timestamp":"20200911112230",
 "tenant_id":"test",
 "biz_params": "{\"pro_inst_id\":[\"5e66a816-152a-4973-8f0c-f982e157533a\",\"e15c5c97-8bd1-4ae2-a9cf-22329297fbd8\"]}",
}
```


**返回参考示例：**


```json

  "state": "SUCCESS",
  "message": "执行成功",

  "timestamp": "2022-06-13 18:27:14",

      {
```
