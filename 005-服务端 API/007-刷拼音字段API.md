# 1.支持版本说明：

v4.2.0版本以上

<a id="BAgHf"></a>


# 2.频次限制说明

为了避免频繁刷拼音字段，平台内部增加了刷新的时间限制，每次刷新后到下次刷新时，要间隔30分钟。判断条件是按照租户ID和刷新的人员ID/部门ID/组织单元ID来判断的。

<a id="sX9e3"></a>


# 3.刷新用户拼音字段

**刷新人员拼音字段，人员ID传-1时，刷新全部，人员ID有值时，按值刷新某一用户的拼音字段**

**接口：**

**{url}**/ego\_base\_info/api/public/pinyin/refreshEmployee

METHOD：GET

入**参**

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **参数名称** | **参数说明** | **请求类型** | **是否必须** | **数据类型** | **schema** |
| employee\_id | employee\_id | query | true | string |  |
| tenant\_id | tenant\_id | query | true | string |  |

**出参：**

{

"code": "",

"data": true,//返回true说明刷新成功，否则刷新失败

"message": "",

"msg": "",

"state": "",

"timestamp": 0

}
