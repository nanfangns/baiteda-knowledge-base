**mysql数据库字段与平台模型字段对应关系表**

|  |  |
| --- | --- |
| 数据库字段 | 平台字段 |
| varchar、svarchar、char | 短文本、数字、整数、人员、数组、人员、附件、部门、地址、图片、自动编号、日期 |
| text、longtext、mediumtext、tinytext | 短文本、长文本、数字、整数、人员、数组、人员、附件、部门、地址、图片、json |
| tinyint、smallint、int、interger、mediumint | 整数 |
| double、float、numeric、REAL | 数字、整数 |
| decimal | 数字 |
| bigint | 整数,日期 |
| datetime、timestamp | 日期 |
| blob、longblob、tinyblob、mediumblob | 长文本 |
| enum | 短文本 |
| DATE、TIME、YEAR | 日期 |
