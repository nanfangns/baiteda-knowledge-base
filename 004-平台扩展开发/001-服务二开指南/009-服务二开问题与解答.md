**问：服务接口请求超时是多少秒？**

答：目前服务的请求超时全部是30s

​

**问：现在平台是否支持OAuth认证？**

答：接口的认证暂时不支持，平台的单点登录支持Oauth2

​

**问：二开中调用查多服务，支持and or查询条件data\_filters 如何设置？**

答：示例说明：


```plain
{
    "data_filters":[
        {
            "type":"conditions",
            "value":"and",
            "children":[
                {
                    "type":"condition",
                    "symbol":"op_equal",
                    "left_variable_bo":{
                        "type":"varchar",
                        "value":"status_type"
                    },
                    "right_variable_bo":{
                        "type":"custom",
                        "value":[
                            "1"
                        ]
                    }
                },
                {
                    "type":"condition",
                    "symbol":"op_equal",
                    "left_variable_bo":{
                        "type":"varchar",
                        "value":"deleted"
                    },
                    "right_variable_bo":{
                        "type":"custom",
                        "value":[
                            "0"
                        ]
                    }
                },
                {
                    "type":"condition",
                    "symbol":"op_no_equal",
                    "left_variable_bo":{
                        "type":"varchar",
                        "value":"employee_id"
                    },
                    "right_variable_bo":{
                        "type":"custom",
                        "value":[
                            "sysadmin"
                        ]
                    }
                }
            ]
        }
    ]
}
```


逻辑关系为： employee\_id != sysadmin and deleted==0 and status\_type==1

说明：

symbol：


```plain
* OP_NO_EQUAL("op_no_equal", "不等于"),
* OP_EQUAL("op_equal", "等于"),
* CONTAINS_ONE("contains_one", "包含任一"),
* IN_CONTAINS("incontains", "包含"),
* UN_CONTAINS("uncontains", "不包含"),
* CONTAINED_IN("containedIn", "含于"),
* CONTAINED_OUT("containedOut", "不含于"),
* BELONG("belong", "属于"),
* UN_BELONG("unbelong", "不属于"),
* OP_GREATER("op_greater", "大于"),
* OP_LESS("op_less", "小于"),
* OP_GREATER_EQUAL("op_greater_equal", "大于等于"),
* OP_LESS_EQUAL("op_less_equal", "小于等于"),
* IS_EMPTY("is_empty", "为空"),
* IS_NOT_EMPTY("is_not_empty", "不为空"),
* MATCHING("matching", "匹配"),
* NOT_MATCHING("not_matching", "不匹配"),
* CONTAINS_IN_WITH_SUB_DEPT("contains_in_with_sub_dept", "含子部门")
```


left\_variable\_bo

type：为字段类型

value：字段id

right\_variable\_bo

type：只允许自定义（custom）

value：数值，使用数组包裹
